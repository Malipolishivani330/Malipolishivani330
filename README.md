# 🔍 How I Approach Troubleshooting

Cloud and DevOps work is not only about deploying systems. It is also about understanding what happens when something fails.

My troubleshooting process is:

### 1. Observe the symptoms

First identify exactly what is failing.

- Application unavailable
- Deployment failure
- Container failure
- Health-check failure
- Connectivity issue
- Infrastructure error

### 2. Collect evidence

I avoid guessing and check the available system signals.

- Application logs
- Container logs
- CloudWatch
- Kubernetes status
- GitHub Actions logs
- Network configuration
- Infrastructure configuration

### 3. Isolate the failure layer

I break the problem into smaller components:

**Application → Container → Service → Load Balancer → Network → Security → Infrastructure**

### 4. Identify the root cause

Check configuration, permissions, networking, dependencies, deployment state, and application health to determine where the issue originates.

### 5. Fix and validate

Apply the appropriate change and verify the complete application or infrastructure flow again.

### 6. Document the resolution

Record the cause, fix, and validation steps so the issue can be understood and diagnosed more efficiently in the future.

> **My goal is not just to make a system work again — it is to understand why it failed.**
